# Gestion360

Plataforma de Gestión de Servicios y Solicitudes.

## Descripción

Gestion360 es un proyecto integrador desarrollado de forma progresiva
para aplicar los conocimientos adquiridos en diferentes cursos de la
carrera de Ingeniería de Sistemas e Informática.

El proyecto utiliza una arquitectura escalable que permite incorporar
funcionalidades correspondientes a diferentes áreas sin perder la
estructura central del sistema.

## Estructura

- `backend/` - Aplicación backend basada en Spring Boot.
- `frontend/` - Aplicación frontend.
- `database/` - Scripts y recursos relacionados con la base de datos.
- `docs/` - Documentación del proyecto.

## Tecnologías principales

- Java
- Spring Boot
- PostgreSQL
- Angular
- Git / GitHub
